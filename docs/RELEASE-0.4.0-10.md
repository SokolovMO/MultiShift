Дата: 12 ноября 2026. Релиз подготовлен, затем опубликован по отдельному запросу владельца.

Готовый каталог: `dist/release-0.4.0-10/`.

- `MultiShift-0.4.0-10-arm64.dmg` — установщик, 99 542 335 байт.
- `MultiShift-0.4.0-10-arm64.zip` — архив Sparkle, 130 287 636 байт.
- `MultiShift-0.4.0-10-source.tar.gz` — соответствующие исходники, включая локальные изменения.
- `appcast.xml` — подписанная лента с описанием изменений на русском и английском.
- `latest.json`, `SHA256SUMS`, `install.sh`, `index.html` и лицензии — комплект публикации.

## Проверено

- Перед подготовкой публичный latest.json сообщал 0.3.3 (9); установленная копия также 0.3.3 (9).
- Использован прежний Ed25519-ключ. Открытый ключ совпадает с установленным приложением.
  Приватный ключ не изменялся и не входит в каталог выпуска или архив исходников.
- Подписи ZIP, DMG и appcast проверены инструментами Sparkle 2.10.0; SHA256 официального
  архива инструментов сверена со значением в prepare_sparkle.sh.
- ZIP распакован повторно; подпись приложения и selftest прошли.
- DMG создан, проверен, смонтирован только для чтения; подпись и selftest вложенного
  приложения прошли. Образ отключён после проверки.
- Файлы новых движков и нативных редакторов в исходном архиве побайтово совпадают с проектом;
  версия в исходниках — 0.4.0, build — 10.
- 23 проверки engine protocol / release distribution прошли. Пять проверок выпуска
  включают отбрасывание подменённых архивов, установщика, исходников и ленты.
- Из окончательного ZIP проверены PNG→JPG, Markdown→PDF, CSV→XLSX, папка→ZIP,
  точный предпросмотр, встроенный FFmpeg, обработанный медиафрагмент и PDF→DOCX.
- Основной функциональный набор ранее прошёл: 416 Python-проверок, 26 пропусков;
  29 Swift-проверок. Изменения подготовки выпуска: версия/build, текст release notes,
  включение отчёта о функциях в исходный архив. Повторная функциональная проверка
  выполнена на упакованной версии 0.4.0.

Сборка: Apple Silicon, macOS 14+, native SDK 27.2, Sparkle 2.10.0 включён.
Приложение подписано ad-hoc; нотарификации Apple нет. Реальная установка обновления
через Sparkle на пользовательскую копию и ограничения из NATIVE-FEATURES-2026-11-12.md
остаются отдельными проверками.
