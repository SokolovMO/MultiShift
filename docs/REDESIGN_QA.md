# multishift 0.3.0 — проверка редизайна

Дата: 23 октября 2026. macOS 27.0.1, Apple Silicon.

Итоговая сборка: `88abe0cf392b-dirty-7d1cbcd71b871f04`. Отпечаток текущих исходников: `7d1cbcd71b871f04d4e6e25f162743d2c9da1b77bc3fe8aecd0389b265211343`. Исходники, установленный bundle и приложение из ZIP-артефакта сверены; бинарник, Info.plist и BUILD.json совпадают.

## Реализовано

Нативный SwiftUI/AppKit интерфейс получил общую монохромную систему поверхностей, текста, кнопок, keycap, состояний и анимаций. Переработаны настройки с боковой навигацией, NSPopover, история, выбор действия, редактор с предпросмотром, onboarding, круговое меню и подробности операции. Добавлены светлая и тёмная иконки. Поддерживаются system/light/dark, Reduce Motion, Reduce Transparency и Increased Contrast.

Применены локальные SwiftUI Expert и Apple Design skills. Из локального MultiSwitcher взяты принципы системной типографики, боковой панели 206 pt и коротких переходов. Зависимости между приложениями нет.

Функции концепта, отсутствующие в настоящем MultiShift (переназначение модификаторов, редактор правил, профили приложений), не добавлены. Существующий движок, идентификаторы действий, настройки, файлы и история сохранены. Контролируемый текст приводится к lowercase отдельно от имён файлов, путей и пользовательских данных.

Цветные traffic lights, стандартный системный файловый диалог и индикатор демонстрации экрана принадлежат macOS. Они оставлены нативными по заданию. Снимки не ретушировались.

## Функциональные проверки через настоящий интерфейс

Тестовые исходники находились в `/private/tmp/MultiShift-redesign-QA-20261023`. Пользовательские документы не изменялись.

- «Открыть файлы…» через нативный диалог: смешанный регистр `MiXeD File Name.PNG` сохраняется в выборе действия, предпросмотре, истории и результатах.

- PNG→JPG: результат 36 527 байт. Повтор установленной версией создал `MiXeD File Name (1).jpg`; существующий JPG сохранился.

- Редактор размера: настоящий предпросмотр 1200×800, сохранение отдельной копии 600×400. Undo через подробности операции переместил эту копию в корзину; исходник сохранился.
- Popover показывает последний результат. Раскрытие истории и переход к PDF-операции с двумя конечными результатами проверены.
- «Показать результаты в finder» выделяет именно `MiXeD File Name (1).jpg` в Finder; путь подтверждён деревом доступности.
- Светлая, тёмная и системная темы переключаются; вложенные окна следуют выбранному оформлению. Исходный режим `system`, русский язык, shift и настройка сохранения рядом с исходником оставлены.

Во время проверки промежуточной раскрытой истории произошёл таймаут UI-инструмента. Снятый стек показал ожидание событий в AppKit, без аварии. После перехода на LazyVStack повторное раскрытие и открытие результата прошли. Это не считается доказанным исправлением исторических SIGABRT.

## Границы приёмки

Сопоставимый замер после чистого фонового запуска без окон: 0.2.1 — RSS 48 960 KiB (47,8 MiB), CPU 0,1%; итоговая 0.3.0 — RSS 47 472 KiB (46,4 MiB), CPU 0,2%. Движок обработки в простое отсутствует. До отложенной инициализации UI промежуточная сборка занимала около 81 MiB; этот расход при старте устранён. Это разовые замеры, не длительный профиль энергопотребления. Новых `MultiShift*.ips` за время проверок 23 октября нет; историческая причина SIGABRT не объявляется исправленной по одному этому факту.

- Системный баннер не удалось подтвердить визуально во время демонстрации экрана. Снимки раздела уведомлений показывают реальное состояние, а не подменённый баннер. Настройки macOS/Фокусирования не менялись.
- Физический drag с удержанием модификатора и появлением кругового меню не воспроизведён средствами UI-автоматизации. Обработка ввода сохранена, но отдельная ручная проверка этого сценария остаётся обязательной перед полной приёмкой.
- Reduce Motion/Transparency/Contrast реализованы и проверены по коду; глобальные настройки доступности пользователя не переключались. Полный прогон всех инструментов во всех этих сочетаниях не выполнялся.
- Это локально подписанная сборка для этого Mac, без нотариализации. Длительный energy/memory profiling не выполнялся.

Таким образом, редизайн реализован, собран, установлен и основные файловые сценарии проверены. Полная приёмка по всем пользовательским критериям остаётся открытой для физического drag и визуального показа системного баннера.
