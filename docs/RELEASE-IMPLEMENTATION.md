# Текущая схема релиза

С 2026-11-06 MultiShift использует самостоятельную статическую раздачу на Vyrex:
https://sokolovmo.ru/multishift/ . Инструкция: [DISTRIBUTION.md](DISTRIBUTION.md).

Убраны обязательные Apple credentials, нотарификация, централизованное создание
кандидатов, GitHub App, панель релизов и каналы beta/stable. Остались локальная
сборка, постоянный ключ Ed25519, подписанные ZIP/appcast, Sparkle и статический сайт.
CI проверяет код; публикация выполняется отдельной локальной командой.

Первый запуск, физические сценарии Finder, совместимость со старыми macOS,
VoiceOver, несколько дисплеев и реальное обновление A → B проверяются отдельно.
Документ описывает реализацию, а не подтверждает прохождение этих проверок.
