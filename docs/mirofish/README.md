# MiroFish: пакет для симуляции пользовательских реакций

Пакет разделён по продуктам. Загружайте материалы одного приложения за один запуск, чтобы агенты не смешивали функции и интерфейсы. Сначала лучше провести короткую пробную симуляцию, затем уточнить сценарии по её результатам.

## Материалы

- `multishift.md` — MultiShift: обработка копий файлов через перетаскивание в круговое меню.
- `multiswitcher.md` — MultiSwitcher: переключение раскладки и исправление текста, набранного не в той раскладке.
- `prompts.md` — готовые запросы для запуска и структура отчёта.

Приоритеты охватывают оба продукта; доверие рассматривается по-разному: сохранность файлов в MultiShift и обработка текста/доступ к клавиатуре в MultiSwitcher.

## Как использовать

1. В MiroFish создайте отдельный проект для каждого приложения.
2. Загрузите соответствующий файл с описанием приложения. Если интерфейсные изображения можно добавить как исходные материалы, добавьте реальные снимки экранов и подпишите каждый: экран, состояние, что пользователь сделал до него. Если загрузчик не принимает изображения, оставьте их для ручной проверки, а в MiroFish передайте текстовые описания.
3. Вставьте соответствующий запрос из `prompts.md` и начните с короткого прогона. В README MiroFish отдельно советуют пробовать менее 40 раундов из-за расхода API.
4. Сохраните вывод и разделите наблюдения на повторяющиеся гипотезы, единичные реакции и вопросы для ручной проверки.
5. Не считайте частоту мнений в симуляции статистикой реальных пользователей. Используйте результат, чтобы выбрать, что показать людям и что проверить на настоящем Mac.

## Что проверить перед запуском

- Версия приложения и соответствие приложенных снимков этой версии.
- Язык интерфейса и macOS.
- Какие функции реально доступны в тестируемой сборке.
- Для MultiSwitcher используйте актуальный исходный проект `/Users/sokolovmo/Documents/MultiSwitcher`; архивная копия внутри этого репозитория не является источником для описания текущей версии.

## Что нужно для самой платформы

MiroFish требует настроить совместимый LLM API и Zep Cloud. Ключи храните только в локальном `.env` MiroFish; не добавляйте их в эти материалы и не отправляйте в переписке. Пакет материалов не запускает приложение и не проверяет действия в macOS.
